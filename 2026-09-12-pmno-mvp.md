# PMNO MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a clickable PMNO MVP that visualizes nearest towers separately from ranked COLLO recommendations and explains the final decision.

**Architecture:** A lightweight static web app keeps the first visualization fast and portable. Candidate scoring is isolated in a small JavaScript domain module so the UI can later swap demo data for the Supabase decision API without redesigning the screen.

**Tech Stack:** HTML, CSS, vanilla JavaScript, Node.js built-in test runner.

**Spec:** `docs/superpowers/specs/2026-09-12-pmno-mvp-design.md`

## Global Constraints

- Dark navy executive dashboard aesthetic.
- Show nearest towers and Top 5 COLLO opportunities as separate concepts.
- COLLO_FIRST is mandatory.
- Target IRR is 10.73%; IRR below target is not viable.
- User-facing terminology is “Kualitas Signal”, not “RF Gap”.
- Demo data must be labeled synthetic/demo.
